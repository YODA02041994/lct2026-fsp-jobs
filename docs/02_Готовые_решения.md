## 8. Выводы

1. Слой вакансий не нужно писать с нуля. Сбор из открытых российских источников плюс открытое API `freehire`
   закрывают каталог за один-два дня. Неделю тратить на сборщики нет смысла.
2. Готового открытого решения, которое связывает подтверждённые спортивные достижения с подбором вакансий, поиск не нашёл.
   Это и есть место для своей работы: профиль достижений ФСП, его проверка и подбор по нему.
3. Среди найденного нет ни одного опубликованного решения этой задачи от других команд. Репозиторий `ekp-parser`
   появился 26.09.2026 и работает с данными ФСП, но решает другую задачу — каталог мероприятий.
