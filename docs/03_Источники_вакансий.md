Запросы выполнены с сервера в России, без ключей и без входа в учётные записи.

| Источник | Запрос | Ответ | Вывод |
|---|---|---|---|
| «Работа России» (trudvsem) | `GET http://opendata.trudvsem.ru/api/v1/vacancies?text=python&limit=2` | 200, JSON, 418 вакансий по слову «python»; по слову «программист» — 1990 | открытое API без ключа, подключается сразу |
| Хабр Карьера | `GET https://career.habr.com/vacancies/rss?currency=RUR&sort=date&type=all` | 200, RSS, 50 последних вакансий | лента без ключа; глубина — только свежие записи |
| getmatch | `GET https://getmatch.ru/api/offers?limit=2` | 200, JSON, 928 предложений | отвечает без ключа; документации и условий использования для этого адреса не нашли — см. раздел 3 |
| freehire | `GET https://freehire.me/api/v1/jobs/search?q=python&countries=RU&limit=2` | 200, JSON, 902 вакансии | открытое API без ключа, описано в документации проекта |

| Источник | Зарплата | Навыки | Формат работы | Грейд | Работодатель | Ссылка на оригинал | Замечание |
