# Источники вакансий

> **Статус после ТЗ (06.10):** внешние источники вакансий в MVP не подключаем — ТЗ прямо исключает парсинг сторонних сайтов и витрину чужих вакансий.
> Вакансии на платформе публикуют работодатели сами. Документ сохранён как справочный; из него остаются полезными правовая рамка (раздел 3)
> и правило «контакты и имена рекрутёров не храним».

Заголовок ответа сообщает лимит 600 запросов. Глубина выдачи ограничена: `offset + limit` не больше 10 000,
страница до 100 записей — выборку режем по источнику или категории. На всю российскую выборку нужно около 260 запросов.

## 3. Правовая рамка

| Норма или дело | Суть | Источник |
|---|---|---|
| ст. 1334 ГК РФ | изготовитель базы данных вправе запрещать извлечение материалов; существенные затраты предполагаются при 10 000 элементов и более | [текст](https://legalacts.ru/kodeks/GK-RF-chast-4/razdel-vii/glava-71/ss-5/statja-1334/) |
| ст. 1335.1 ГК РФ | правомерный пользователь может извлекать несущественную часть; неоднократное извлечение, противоречащее нормальному использованию базы, не допускается | [текст](https://legalacts.ru/kodeks/GK-RF-chast-4/razdel-vii/glava-71/ss-5/statja-1335.1/) |
| «ВКонтакте» против «Дабл» | суд по интеллектуальным правам: важно, кто понёс затраты на базу; дело закончилось мировым соглашением | [Право.ru](https://pravo.ru/news/243021/) |
| HeadHunter против «Стафори» | иск отклонён; ФАС предписала рассматривать заявки на API без дискриминации | [Право.ru](https://pravo.ru/news/202295/) |
| 152-ФЗ, ст. 10.1 | согласие на распространение персональных данных оформляется отдельно | [текст](https://www.consultant.ru/document/cons_doc_LAW_61801/591acc70f577873c1ee54765eda110b7a0271eaf/) |

Правила для прототипа:
1. храним поля вакансии и короткую выдержку, показываем ссылку на оригинал;
2. контакты и имена рекрутёров не храним и не показываем — они есть в ответах «Работы России»;
3. соблюдаем условия источника и `robots.txt`;
4. закрытые вакансии убираем из выдачи.

## 5. Риски

| Риск | Что известно |
|---|---|
| Блокировки по адресу | сайт trudvsem.ru из-за рубежа не открывается, адрес API доступен; superjob.ru из-за рубежа показывает проверку |
| Нет признака удалёнки и грейда | в «Работе России» этих полей нет — определяем по тексту |
| Дубли между площадками | одна вакансия встречается на нескольких площадках — нужна дедупликация по работодателю, названию и городу |
| Недокументированные адреса | карьерные страницы Яндекса, VK, Сбера, Ozon могут измениться без предупреждения |
| Персональные данные | контакты рекрутёров в ответах «Работы России» и в постах Telegram |
