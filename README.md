# Карьера ФСП — платформа подбора ИТ-специалистов с подтверждённым профилем достижений

Решение задачи специального трека хакатона «Лидеры цифровой трансформации 2026».
Постановщик — Федерация спортивного программирования (ФСП).

Задача по ТЗ: веб-платформа с обратной механикой найма. Кандидат проходит опрос и тест и получает категорию
(специализация × грейд); работодатель описывает потребность, получает подборку кандидатов с обоснованием и сам направляет
приглашение с зарплатой; контакты открываются после согласия кандидата. Профиль кандидата связывается с ФСП ID
и обогащается подтверждёнными достижениями.

**Состояние на 07.10.2026:** прототип работает целиком и развёрнут; документация по восьми разделам ТЗ и презентация собраны.

## Запуск

В Docker (PostgreSQL, API, nginx) — нужен Docker с Compose v2:

```bash
docker compose up --build
```

Через 1–2 минуты откройте http://localhost:8080. База наполняется демонстрационными данными при первом старте.

Без Docker — нужен Python 3.12:

```bash
./run.sh dev                 # http://localhost:8000; другой порт: PORT=8015 ./run.sh dev
```

Проверка после запуска:

```bash
./run.sh smoke               # сквозной сценарий ТЗ по HTTP, 24 шага (для запуска без Docker: BASE=http://localhost:8000 ./run.sh smoke)
./run.sh test                # автотесты
```

Настройки — переменные `FSP_*` (образец `.env.example`); без почтового сервера и ключа внешней модели всё работает в
демонстрационном режиме. Подробно — раздел 8 документации к сдаче (`docs/10_Документация_к_сдаче.md`).

## Что внутри

Фронтенд — Vue 3 без сборки (`frontend/`), два кабинета: кандидата и работодателя. Бэкенд — FastAPI (`backend/app/`): тест на
грейд из параметризованных заданий (`services/testing/`), подбор с объяснимыми слагаемыми (`services/matching*.py`), ФСП ID
по OpenID Connect (`routers/fsp.py`), разбор резюме и потребностей. Хранение — PostgreSQL (SQLite для локального запуска).
Проверка механик на синтетике и поиск формулы подбора — `scripts/` и `scripts/evolve/`.

## Использование ИИ

Рисерч, код и документация готовятся с ИИ-ассистентами (Claude Code, агент «Йода») под контролем участников команды.

Модель DeepSeek V4.1 Flash (прямой API) используется ещё в трёх местах, и все описаны:
- **в продукте** — дополнительный разбор текста потребности работодателя и PDF-резюме. Модель получает текст только после
  обезличивания (ФИО, телефоны, почта, Telegram вырезаны), её ответ проверяется по справочникам; без ключа всё работает на правилах
  (`docs/07`, раздел 3);
- **в разработке** — как оператор мутации при эволюционном поиске формулы подбора: модель предлагает изменения, оценивает их
  программа-фитнес на синтетических мирах, результат проверен на мире, который в поиске не участвовал (`docs/09`,
  раздел «Самоулучшение формулы»; код — `scripts/evolve/`). Мнение модели нигде не используется как оценка;
- **в банке заданий** — 40 из 136 шаблонов написаны моделью по заданной ячейке «специализация × грейд», прошли валидатор
  (исполнение ключей, детерминизм по зерну, запрет опасных конструкций) и четыре независимых ревью по официальной документации;
  35 исправлены, 3 одобрены, 2 удалены и перегенерированы (`docs/08`, раздел 7; реестр со статусом и источником проверки —
  `backend/app/services/testing/bank/generated/REGISTRY.md`). Остальные 96 шаблонов написаны вручную.
Правила работы агентов — [AGENTS.md](AGENTS.md).
