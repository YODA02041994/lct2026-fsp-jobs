# ФСП-вакансии — платформа поиска и подбора ИТ-вакансий с подтверждённым профилем достижений

Решение задачи специального трека хакатона «Лидеры цифровой трансформации 2026».
Постановщик — Федерация спортивного программирования (ФСП).

Формулировка из регламента: «Создание агрегированной платформы для поиска и подбора ИТ-вакансий».
В анонсах организатора: платформа-агрегатор ИТ-вакансий с верифицированным профилем достижений участника ФСП.

**Состояние на 04.10.2026:** техническое задание ещё не выдано (откроется 5 октября в личном кабинете).
В репозитории — рисерч и заготовка плана. Кода пока нет.
